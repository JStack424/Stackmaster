# Valheim QoL Mods

A workspace for small, configurable Valheim quality-of-life mods, beginning with inventory sorting and chest-storage workflows.

## Distribution target

- Thunderstore packages
- Installable and manageable through r2modman

## Status

Researching the current Valheim modding, testing, packaging, and publishing workflow before choosing the first mod's exact behavior and architecture.

## Project principles

- Keep each feature focused and configurable.
- Split features into separate packages when that produces cleaner dependencies or player controls.
- Design for multiplayer compatibility deliberately rather than assuming client-only behavior.
- Keep generated files, local game assemblies, profiles, and credentials out of git.
